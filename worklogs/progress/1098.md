## Implementation Summary
Streamers invite each other to collaborate on a live broadcast.

## Requirements Analysis
Based on the issue requirements, we need to implement:

### API Endpoints
1. **POST** `/invite` - Create collaboration invite
   - Request: `{ from_creator_id, to_creator_id, message?, stream_id }`
   - Response: `{ invite_id, status: pending }`

2. **POST** `/respond` - Respond to collaboration invite
   - Request: `{ invite_id, decision: accept|decline }`

3. **GET** `/invites` - List invites
   - Query: `?creator_id`
   - Returns: incoming/outgoing invites

### Business Rules
- Cap pending invites per creator pair to 1
- Tests must cover lifecycle and deduplication
